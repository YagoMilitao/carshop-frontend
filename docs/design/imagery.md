# CarShop Imagery System

## Purpose

This document defines how photography and visual media should be selected, composed, displayed, and reviewed across the CarShop frontend.

For CarShop, photography is not decoration.

Photography is evidence of craftsmanship.

The imagery system must reinforce:

- automotive interiors;
- upholstery quality;
- restoration;
- custom work;
- material quality;
- stitching;
- transformation;
- trust.

Agents must not select imagery only because it looks visually impressive.

---

# Core Principle

The product being sold is not the vehicle itself.

The product is the quality of the interior craftsmanship.

Therefore:

Interior photography has priority over exterior vehicle photography.

---

# Image Priority

Use imagery in this order whenever appropriate:

1. Real CarShop completed work
2. Real CarShop before/after work
3. Real CarShop craftsmanship details
4. Real shop/workshop photography
5. Approved temporary placeholders
6. Carefully selected stock/reference photography only when necessary

Real work always has higher value than generic premium imagery.

---

# Primary Subjects

Preferred image subjects include:

- completed automotive interiors;
- seats;
- leather upholstery;
- stitching;
- seat panels;
- door panels;
- dashboards;
- center consoles;
- headliners;
- carpets;
- steering wheel upholstery;
- restored classic interiors;
- modern custom interiors;
- material details;
- before/after transformations.

---

# Secondary Subjects

Secondary imagery may include:

- exterior vehicle photography;
- workshop environment;
- tools;
- material rolls;
- sewing equipment;
- craftsmen at work;
- detail preparation.

These should support the story.

They should not replace interior craftsmanship as the main subject.

---

# Exterior Vehicle Rule

Exterior vehicle photography is allowed when it provides context.

Good example:

A completed classic car shown before presenting its restored interior.

Bad example:

A homepage dominated by a sports-car exterior with no visible upholstery work.

The website should never look like a dealership or tuning shop unless the content explicitly supports that story.

---

# Hero Imagery

The homepage Hero should feature strong automotive interior photography.

Ideal Hero photography should communicate quality immediately.

Preferred characteristics:

- strong interior composition;
- visible upholstery detail;
- premium material;
- clean lighting;
- clear focal point;
- enough negative space for composition when text shares the area.

The Hero image does not need to contain text space if the layout positions text separately.

---

# Hero Image Selection

Prefer images showing:

- complete custom interior;
- front seats and dashboard;
- premium leather restoration;
- strong stitching detail within a wider interior context.

Avoid Hero images showing only:

- vehicle exterior;
- steering wheel alone;
- isolated logo;
- generic mechanic work;
- stock luxury car imagery unrelated to upholstery.

---

# Craftsmanship Detail Photography

Close-up images are highly valuable.

Use details such as:

- stitching;
- leather grain;
- seams;
- piping;
- embroidery;
- material transitions;
- seat contours;
- handcrafted finishing.

Detail photography helps communicate quality that may be missed in wide images.

---

# Wide vs Detail Balance

A project should ideally include both:

Wide images

to show the final interior.

and

Detail images

to prove workmanship.

Do not build galleries containing only wide shots or only extreme close-ups.

---

# Before & After

Before/after imagery must prioritize truthfulness.

Images should ideally:

- show the same area;
- use similar framing;
- use similar camera position;
- maintain realistic color;
- clearly communicate transformation.

Do not artificially exaggerate the difference.

---

# Before & After Forbidden Behavior

Never:

- intentionally darken the Before image;
- oversaturate the After image;
- apply different dramatic filters;
- crop the images misleadingly;
- use unrelated vehicle interiors;
- fabricate transformations.

The comparison must represent the real work.

---

# Project Galleries

Project galleries should tell a visual story.

Possible order:

1. Hero/final result
2. Wide interior
3. Driver/passenger view
4. Seat details
5. Stitching/material detail
6. Door panels/dashboard
7. Before/after when available
8. Additional craftsmanship details

The exact order depends on available media.

---

# Editorial Composition

Not every gallery image should have the same size.

Public pages may use:

- dominant images;
- supporting images;
- landscape images;
- portrait details;
- controlled asymmetry;
- occasional full-bleed imagery.

Variation should support storytelling.

Do not create visual randomness.

---

# Image Ratios

Prefer a small, controlled set of aspect ratios.

Possible system:

## Landscape

`16:9`

Use for:

- Hero support imagery;
- wide interior photographs;
- project banners.

## Editorial Landscape

`4:3`

Use for:

- portfolio projects;
- interior storytelling.

## Portrait

`3:4`

Use for:

- detail photographs;
- seat details;
- editorial layouts.

## Square

`1:1`

Use sparingly.

Square should not become the default simply because grids are easy to implement.

---

# Aspect Ratio Rule

The ratio should serve the photograph.

Do not force all project images into identical crops when important interior details would be lost.

When standardized previews are required, use intelligent cropping and preserve the original image for detail views.

---

# Image Cropping

Do not crop away:

- stitching details;
- seat contours;
- material transitions;
- important dashboard elements;
- core upholstery work.

The focal point is craftsmanship.

---

# Object Position

When using cover-based image containers, inspect the focal point.

Agents must not blindly use center crop.

Use intentional object positioning when necessary.

---

# Color Accuracy

Photography should preserve realistic material color.

This is especially important for:

- leather;
- vinyl;
- fabrics;
- Alcantara;
- stitching;
- interior trim.

Do not apply strong brand-color grading to real project images.

---

# Image Filters

Avoid global filters.

Do not automatically apply:

- grayscale;
- sepia;
- heavy contrast;
- warm orange filters;
- cinematic teal/orange;
- dark overlays.

The work should look authentic.

---

# Overlays

Use overlays only when needed for readability or composition.

Preferred options:

- subtle localized dark gradient;
- restrained neutral overlay.

Avoid:

- Cognac overlay;
- automotive red overlay;
- heavy full-image black layer.

If text cannot be read over an image without destroying the image, reconsider the layout.

---

# Photography vs Decorative Graphics

Photography has higher priority than decorative graphics.

Do not compensate for weak imagery by adding:

- gradients;
- abstract blobs;
- glowing shapes;
- random lines;
- fake 3D objects;
- automotive icons.

Improve the composition instead.

---

# Stock Photography

Stock photography should be temporary or intentionally selected.

Use stock only when real CarShop media is unavailable.

Stock must represent:

- realistic automotive upholstery;
- interiors;
- craftsmanship;
- materials.

Avoid stock images that look like:

- luxury dealership advertising;
- racing advertisements;
- generic mechanic imagery;
- staged corporate workshop scenes.

---

# Stock Disclosure

During development, agents should clearly identify placeholder imagery.

Do not present stock imagery as actual CarShop work.

Example internal labeling:

`placeholder image`

or

`temporary visual reference`

Production content must not misrepresent another vehicle or business as a CarShop project.

---

# AI-Generated Imagery

AI-generated imagery should not be presented as real CarShop work.

It may be used for:

- internal visual exploration;
- wireframe/mockup support;
- conceptual design testing;

when clearly treated as placeholder content.

Do not use AI imagery to fabricate:

- completed customer projects;
- testimonials;
- shop facilities;
- craftsmanship evidence.

Authenticity matters.

---

# Reference Images

Images from reference websites are research material.

They must not be copied into production.

Agents may study:

- composition;
- framing;
- visual hierarchy;
- photography style.

They may not reuse the actual photographs.

---

# Workshop Photography

Real workshop imagery can strengthen trust.

Useful subjects:

- craftsman sewing;
- material preparation;
- seat disassembly;
- upholstery fitting;
- stitching process;
- tools;
- workbench;
- workshop environment.

Use authentic photography whenever possible.

---

# People in Imagery

People may appear when they support authenticity.

Good examples:

- craftsman working;
- customer interaction when authorized;
- team portrait;
- real workshop process.

Avoid generic corporate team stock photography.

---

# Materials Photography

Material imagery may show:

- leather;
- vinyl;
- suede;
- Alcantara;
- fabrics;
- thread;
- piping.

These images should emphasize:

- texture;
- color;
- finishing;
- tactile quality.

---

# Service Imagery

Each service may have associated imagery.

Example:

Restoration

→ before/after interior

Custom Interiors

→ finished custom seating/detail

Repairs

→ repaired seat/headliner/panel

Images should communicate the service without relying on generic icons.

---

# Our Work Imagery

The homepage `Our Work` section should prioritize the strongest projects.

Selection criteria:

- image quality;
- visible craftsmanship;
- variety;
- strong composition;
- representative service;
- authenticity.

Do not choose projects only because the vehicle itself is expensive.

The upholstery quality matters more.

---

# Portfolio Diversity

Portfolio selection should show variation when real work allows it.

Possible variety:

- classic vehicles;
- modern vehicles;
- different interior colors;
- different materials;
- restoration;
- custom interiors;
- repair work.

Do not fabricate diversity that does not exist in real projects.

---

# Testimonial Imagery

Customer photos are optional.

Do not require an avatar for every testimonial.

If no real customer image exists, prefer no image over a fake stock portrait.

---

# Business Imagery

The About/Contact experience may include:

- storefront;
- workshop;
- team;
- workbench;
- materials;
- process.

These images support local-business credibility.

---

# Image Quality

Production images should be:

- sharp;
- correctly exposed;
- appropriately cropped;
- sufficiently high resolution;
- free from visible compression artifacts.

Do not upscale poor-quality imagery aggressively just to fill large layouts.

---

# Performance

High visual quality must not destroy page performance.

Frontend implementation should consider:

- Next.js Image;
- appropriate `sizes`;
- responsive image delivery;
- image dimensions;
- lazy loading where appropriate;
- prioritized loading only for critical imagery;
- modern formats when supported.

---

# Hero Performance

The primary Hero image may be performance-critical.

Evaluate whether it should receive loading priority based on actual implementation and LCP behavior.

Do not mark every image as priority.

---

# Layout Shift

Images must reserve layout space.

Use:

- width/height;
- aspect ratio;
- stable containers.

Avoid content movement while images load.

---

# Mobile Images

Do not assume the desktop crop works on mobile.

Mobile may require:

- different aspect ratio;
- different crop;
- different focal positioning;
- different image order.

Important craftsmanship details must remain visible.

---

# Accessibility

Every meaningful image must have appropriate alternative text.

Alt text should describe relevant visual content.

Example:

Good:

`Tan leather front seats with diamond-pattern stitching after restoration`

Poor:

`car image`

Poor:

`beautiful amazing premium interior`

Alt text should be useful, not promotional.

---

# Decorative Images

Decorative imagery that provides no meaningful content may use empty alt text when technically appropriate.

Agents must determine this intentionally.

Do not omit alt attributes accidentally.

---

# Alt Text and Project Data

When images belong to projects and the backend provides image alt metadata, prefer that data when valid.

Do not invent highly specific details that are not visible or known.

---

# Image Captions

Captions may be useful for:

- material information;
- project context;
- before/after explanation;
- craftsmanship detail.

Do not caption every image unnecessarily.

---

# Image Text

Avoid embedding important text inside image files.

Text should normally remain HTML.

Benefits:

- accessibility;
- responsiveness;
- SEO;
- localization;
- readability.

---

# Logo Usage

The CarShop logo should not be baked into photographs.

Use the actual brand asset separately.

Do not add watermarks unless this becomes an explicit business requirement.

---

# Watermarks

Avoid intrusive image watermarks by default.

They reduce photography quality.

If intellectual-property protection becomes a requirement, define a separate approved watermark strategy.

---

# Image Borders

Photography generally should not require borders.

Use layout, contrast, and spacing.

Subtle borders may be used if required by a specific composition.

---

# Image Radius

Use restrained radius.

Possible directions:

- square edges;
- subtle radius.

Avoid highly rounded automotive photographs.

Large pill-like photography is not part of the CarShop direction.

---

# Image Shadow

Avoid generic card shadows around photographs.

Photography should feel integrated with the page.

---

# Hover Effects

Portfolio imagery may use subtle interaction.

Allowed examples:

- small scale;
- controlled crop change;
- slight overlay;
- title reveal.

Avoid effects that hide craftsmanship or distort the photograph.

---

# Motion and Imagery

Parallax or scroll-based effects should be used only when they genuinely improve the experience.

Do not implement motion simply because automotive websites often use it.

Performance and reduced-motion accessibility are mandatory considerations.

---

# Placeholder Strategy

When real imagery is not yet available, agents should:

1. preserve the intended layout ratio;
2. use clearly temporary assets;
3. document required final image type;
4. avoid designing around placeholder-specific details.

Example requirement:

`Hero image needed: wide high-resolution photo of completed custom automotive interior, preferably showing front seats and dashboard.`

This is better than selecting a random sports-car image.

---

# Image Requirement Specification

When requesting media from the business, describe the need explicitly.

Example:

## Homepage Hero

Need:

- 1 strong completed interior photo;
- landscape orientation;
- high resolution;
- visible seats and dashboard;
- minimal clutter;
- natural color;
- strong craftsmanship detail.

## Before & After

Need:

- same vehicle;
- same interior area;
- similar camera position;
- before restoration;
- after restoration.

## Our Work

Need:

- 3–6 strongest completed projects;
- mix of wide and detail shots.

---

# Content Authenticity

Agents must never invent project context based only on an image.

Do not infer:

- vehicle model;
- material type;
- customer name;
- project date;
- service performed;

unless the data is actually available.

---

# Image Review Checklist

Before approving imagery, ask:

- Does this image show CarShop's actual product?
- Is the interior craftsmanship visible?
- Is the image authentic?
- Is the crop intentional?
- Are important details preserved?
- Does the image support the section objective?
- Is color realistic?
- Does mobile require a different crop?
- Does the image have correct alt text?
- Is performance considered?
- Are we accidentally making the site look like a dealership?

If the answer reveals a problem, reconsider the image.

# Agent Rules

Agents working with imagery must:

1. Read `visual-direction.md`.
2. Read `references.md`.
3. Read this document.
4. Prefer real CarShop work.
5. Never reuse competitor/reference photography.
6. Never present placeholders as real business work.
7. Preserve realistic material color.
8. Prioritize interiors over exterior car imagery.
9. Specify image requirements when media is missing.
10. Consider desktop and mobile crops independently.
11. Use meaningful alt text.
12. Consider image performance.
13. Avoid decorative automotive stock imagery.
14. Never fabricate project information from photographs.

---

# Final Principle

Photography is proof.

The user should not need a paragraph explaining that CarShop produces quality work if the photography already demonstrates it.

Show the craft.

Show the materials.

Show the transformation.

Show the result.
