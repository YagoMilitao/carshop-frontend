# CarShop Approved Visual References

## Purpose

This document defines the approved visual and business references for the CarShop public-facing experience.

References exist to help agents understand the automotive upholstery market, visual patterns, content hierarchy, photography usage, craftsmanship communication, and conversion strategies.

References are inspiration sources.

They are NOT templates.

Agents must never reproduce another company's visual identity, copy distinctive layouts, copy written content, or recreate a reference website section-by-section.

---

# Reference Hierarchy

When making visual decisions, use the following priority:

1. Approved CarShop Figma
2. `docs/design/*`
3. Approved references listed in this document
4. Existing CarShop components
5. General design knowledge

References cannot override an approved CarShop design decision.

# Reference Pattern Summary

The automotive upholstery references consistently reinforce several important concepts.

CarShop should learn from these patterns.

## Craftsmanship

The work must feel handmade and specialized.

Avoid presenting upholstery as a commodity.

---

## Transformation

Customers care about the difference between the original interior and the finished work.

Before/after content should be prominent.

---

## Materials

Leather, vinyl, suede, Alcantara, fabrics, stitching, and finishing details can become visual storytelling elements.

---

## Photography

Completed automotive interiors are more persuasive than decorative UI.

Photography should frequently dominate the composition.

---

## Trust

Local automotive businesses depend heavily on trust.

Relevant trust signals include:

- years of experience;
- customer reviews;
- completed projects;
- craftsmanship;
- warranties when actually offered;
- location;
- phone;
- opening hours;
- service area.

Never invent trust signals.

---

## Conversion

A visitor should always understand how to start a project.

Relevant CTAs may include:

- Get a Quote
- Get a Free Quote
- Start Your Project
- Contact Us
- Call Us

The final wording must reflect the actual CarShop business process.

# Reference Evaluation Framework

Before using a visual reference, ask:

## 1. Does it reinforce craftsmanship?

If not, it may not be appropriate.

## 2. Does photography support the product?

The product is automotive interior craftsmanship.

## 3. Does it feel appropriate for a real US local business?

Visual sophistication must not destroy credibility.

## 4. Does it support the CarShop visual direction?

Reference trends must not override the design system.

## 5. Is the pattern useful or merely decorative?

Prefer functional visual decisions.

---

# Reference Usage Example

BAD:

> This Dribbble page looks cool, so I will recreate its hero.

GOOD:

> This reference demonstrates a useful asymmetrical image composition. I can apply the composition principle while preserving CarShop typography, colors, photography, spacing, and brand identity.

# Agent Decision Rule

When an agent proposes a visual pattern inspired by a reference, it must be able to explain:

1. Which reference principle inspired the decision.
2. Why the pattern is appropriate for CarShop.
3. How it was adapted to the CarShop design system.
4. Why it does not conflict with approved Figma or design documentation.

If the agent cannot answer these questions, the reference should not influence the implementation.

---

# Final Principle

CarShop should learn from the best automotive and upholstery experiences without becoming a copy of any of them.

References provide context.

The CarShop design system provides identity.
