# Rule: Security

- No agent loads a full `.env` or exposes secrets, tokens, or passwords in
  code, comments, specs, plans, or documentation.
- `.env.example` documents only variable names, never real values.
- The Obsidian vault never stores secrets, tokens, or `.env` content (see
  [docs/context/obsidian.md](../context/obsidian.md)).
- Sensitive data (e.g., customer personal data) is not logged in plain text
  or included in specs/plans unnecessarily.
- See also [docs/rules/spec-security.md](./spec-security.md) for specific
  rules on specs/plans generated by the workflow.
