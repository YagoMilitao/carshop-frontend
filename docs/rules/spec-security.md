# Rule: Spec and Plan Security

- Specs (`specs/CARSHOP-XX/`) and plans (`plan.md`) generated by the workflow
  never include secrets, tokens, passwords, or `.env` content.
- Never copy real environment variable values into a spec/plan/docs — only
  variable names, when relevant.
- Specs/plans do not expose customer personal data unnecessarily; if a real
  example is needed for context, use fictitious/anonymized data.
- `spec-writer` and `plan-writer` are responsible for this check before
  persisting the corresponding file.
